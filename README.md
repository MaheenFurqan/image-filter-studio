# Image Filter Studio

A C++ console-based image processing application developed as an Object-Oriented Programming semester project.

The application works with real JPG and PNG images, allowing users to load an image, build a filter pipeline, apply multiple image filters, preview the result, and save the processed image.

## Features

- Load and save JPG/PNG images
- Apply multiple image filters through a filter pipeline
- ASCII preview of images in the console
- Admin and Customer user roles
- Customer registration and login
- Filter catalog management
- Customer and session management
- Persistent data storage using text files

## Image Filters

The project includes 10 filters:

- Grayscale
- Invert / Negative
- Brightness Adjust
- Contrast Stretch
- Red Channel Only
- Green Channel Only
- Blue Channel Only
- Box Blur (3×3)
- Flip Horizontal
- Flip Vertical
